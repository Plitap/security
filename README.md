# PLITAP · Безопасность

Сквозная проработка безопасности PLITAP и проверка предположений о защите системы.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Модель угроз для плиток, ключей, клиентов и сетевого взаимодействия.
- Исследование подделок, повторов, конфликтующих операций и отказов.
- Публичные результаты проверок и рекомендации по применению защитных механизмов.

## Границы направления

Защитный код размещается в соответствующих [core](https://github.com/Plitap/core), [network](https://github.com/Plitap/network), [node](https://github.com/Plitap/node) и [client](https://github.com/Plitap/client). Нормативные требования относятся к [spec](https://github.com/Plitap/spec). Наличие этого репозитория не означает выполненный аудит или доказанную безопасность.

## Структура

| Раздел | Назначение |
|---|---|
| [`threat-model/`](threat-model/) | Модель угроз, границы доверия, предположения и сценарии атак. |
| [`reviews/`](reviews/) | Подготовленные к публикации результаты проверок с указанием охвата и ограничений. |
| [`guidance/`](guidance/) | Рекомендации разработчикам по использованию защитных механизмов. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Общие вопросы модели защиты можно обсуждать в [Issues](https://github.com/Plitap/security/issues). О возможной уязвимости сообщайте [приватно через GitHub](https://github.com/Plitap/security/security/advisories/new).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
